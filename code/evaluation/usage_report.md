## Final full-dataset run

The final `output.csv` was written by `python3 code/main.py --strict` with `DELETION_AUDIT_OFFLINE=1`: that run itself made **no model calls**. It reads every LLM result from the committed cache in `code/llm_cache/`. The calls below are the ones whose cached results it read, so they are the model cost of producing `output.csv`. A call counts here when its result is still in the cache (`code/llm_cache/<purpose>/<cache_key>.json`).

- Provider: Anthropic (Claude API, Messages endpoint, standard rate; no batch, no prompt caching).
- `evidence_extraction`: one call per PDF or image evidence file, reading it into snapshot-shaped records.
- `request_classification`: batched calls deciding whether each distinct `request_text` asks for deletion. The batches covered every distinct request text in the full request set, the 32 samples and our evaluation cases, so the token counts slightly overstate the cost of the 518 requests alone.
